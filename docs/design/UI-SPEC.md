# Gauge · 量化人生 — UI 规范

**气质**：温暖叙事 + 冷静数据（P11）  
**PRD**：[docs/product/PRD.md](../product/PRD.md)  
**开发**：[docs/development/README.md](../development/README.md)

---

## 1. 设计原则

1. **数据是仆人**：数字旁边留叙述空间；关键决策页「最不想失去的 3 样」视觉权重 ≥ 任何条形图。
2. **无焦虑 KPI**：禁止 streak 火焰、排行榜、人生总分、「你击败了 X% 用户」。
3. **轨迹无偏见**：垂直时间线；锚点 A 表示「根」，不表示「落后」；禁止地图式「离 A 越远越成功」。
4. **决策并列**：结果页多 **PathCard** 横滑或纵向并列；禁止单一 Winner 皇冠动画。
5. **可关闭感**：设置中说明指标可忽略；今日环仅为「参考对齐」。

## 3. 字体与间距

| 级别 | 规格 | 用途 |
|------|------|------|
| H1 | 28 / semibold | 页面标题 |
| H2 | 22 / semibold | 区块标题 |
| Body | 16 / regular | 正文、叙述 |
| Caption | 13 / regular | 假设、免责声明 |
| Mono | 14 / tabular nums | 金额、分钟数 |

- 页面水平边距：**20**
- Card 内边距：**16**
- 区块间距：**24**

## 4. 组件库

### 4.1 `Screen`

- 暖底 `#F7F5F2`，SafeArea，可选 `scroll`
- 支持 `title` + `subtitle`（叙事一句）

### 4.2 `Card`

- 白底、圆角 **12**、浅阴影或 `border` `#E8E4DF`
- 变体：`default` | `path` | `disclaimer`

### 4.3 `SliderField`

- 范围 **1–10**，左侧标签 + 右侧当前值
- 用于：价值观、精力、成长评分等
-  accessibility：VoiceOver 读「成长权重，7，共 10」

### 4.4 `AlignmentRing`

- 圆环展示 **对齐度** 0–100（非分数排名）
- 中心：今日日期 + 一句主线摘要（截断）
- 副文案：「与主线的参考对齐，不是人生评分」

### 4.5 `Sparkline`

- 7 日折线：energy / storyline_focus / mood 可切换或叠层（MVP 单指标即可）
- 无动画粒子；更新时简单淡入

### 4.6 `PathCard`

- 标题：接受 / 留任 / 条件性谈判
- 分项条：财务、时间、成长、稳定（0–100，**不隐藏弱项**）
- 可选 `referenceScore` 小字：「综合参考 · 非唯一建议」
- 可逆性标签 + 2–3 条假设 bullet
- **禁止**「推荐」角标独占一卡

### 4.7 `TimelineNode`

- 垂直线 + 节点圆点
- **锚点 A**：accent `#C4A574`、较大节点、固定于时间线顶端或叙事起点
- 普通阶段：主色绿节点 + 标题 + 日期范围 + `narrative` 多行
- 当前站 B：描边强调，无「进度百分比成功论」

### 4.8 `StepIndicator`

- Offer 向导 4 步：情境 → 薪酬 → 时间 → 底线
- 当前步主色，已完成步实心，未完成灰

### 5.5 Offer 向导（四步）

1. **情境**：当前角色、可选叙述  
2. **薪酬**：当前年薪、Offer 年薪  
3. **时间**：通勤、加班（现 vs 新）  
4. **底线**：最不想失去的 3 样（必填）+ 成长 1–10  

每步底部：`StepIndicator` + 上一步 / 下一步。

## 7. 设置页

- 编辑人生主线、价值观滑条  
- **导出 JSON**  
- **产品原则**（只读，来自 PRD 话术摘要）  
- 关于：Gauge · 量化人生 / 版本号  
- **无**账号、无排行榜入口  

---

## 8. 文案规范

| 场景 | 推荐 | 避免 |
|------|------|------|
| 对齐环 | 「今日与主线的参考对齐」 | 「人生得分」 |
| 路径对比 | 「较优路径参考」 | 「最优解，就选这个」 |
| 锚点 A | 「你的锚点」 | 「起点等级 Lv.1」 |
| 趋势 | 「近 7 日波动」 | 「你退步了」 |

**产品原则短版（设置页）**：

> 数据是仆人，不是主人。  
> 指标可以关掉；叙述与底线不能省略。  
> 关键节点给你 2～3 条路，每条都有假设和复盘日。

---

## 9. 无障碍

- 所有 Slider 绑定可读数值  
- PathCard 分项用文本列表复述，不单靠颜色  
- 免责声明在结果页**首屏可见**，不需滚动才看到（小屏可折叠但默认展开）

---

## 10. Web 特定

- `document.title`：**量化人生**  
- 最大内容宽度 **480** 居中，模拟手机壳（可选）  
- Tab 栏固定底部，与 RN Web 一致  

---

## 11. 禁止清单（设计评审）

- [ ] 人生总分 / 等级 / 排行  
- [ ] 离 A 越远地图越亮  
- [ ] 单 PathCard 放大 + 「Winner」  
- [ ] 红色闪烁 KPI 提醒  
- [ ] 未填「最不想失去的 3 样」仍可出结果

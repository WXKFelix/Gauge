## 1. 产品愿景

**量化人生的目的**：让每个人的人生可以通过**数据**得到**管理和提升**。

呈现给用户的内容必须同时满足两点：

1. **对 TA 有帮助**——能支持看清现状、做选择、调整节奏，而不是制造焦虑或虚荣指标。  
2. **是 TA 感兴趣的**——用户主动选择关心的方向（职业、健康、财务、关系、成长、日常生活等），未选内容不强行推送。

在此前提下，APP 帮助用户在可测量的维度上看见轨迹，在关键节点获得可执行参考方案，**有的放矢**，而不是被数字奴役。

核心隐喻：

- 你在地球上的 **A 点** 出生；前约 20 年，生活半径大概率仍在 A 附近（家庭、学校、社区）。
- 之后你可能前往 **B、C、D…** 各点：求学、工作、迁徙、旅行；在每处留下回忆与关系。
- 也有人终其一生几乎不离开 A；这同样是一种完整的人生。
- 离开这个星球时，你可能仍在 A，也可能在任意一点——**终点坐标不定义人生价值，轨迹与体验才重要**。

产品不回答「人生能否被完全量化」（不能），而回答：**在哪些维度量化最有帮助，以及如何与不可量化部分共存**。

## 2. 问题与机会

### 2.1 用户痛点

| 痛点 | 表现 | APP 如何回应 |
|------|------|----------------|
| 方向模糊 | 「过得还行，但不知道在优化什么」 | 人生意义分 + 阶段进度 + 坐标叙事 |
| 消耗感 | 资产（能力/储蓄）增长，但工作量吞噬体验 | 多巴胺 proxy：资产 − 工作量 |
| 关键选择焦虑 | 升学、换城、换工作、结婚、生育、退休 | **节点顾问**：基于阶段与指标的参考方案（非唯一真理） |
| 日常脱节 | 宏大目标与每日行为无关 | 生活利用率/穿搭等「贴身指标」连接每日自评 |
| 指标暴政 | 为步数、书单数字而活 | 产品原则：数据是工具，价值由用户定义 |

### 2.2 产品定位

- **品类**：个人人生状态仪表盘 + 人生坐标日记 + 关键节点决策辅助（轻量）。
- **与本仓库关系**：Web 端为 **量化人生** 演示与 MVP；同一套模型可延伸为独立 APP 壳。
- **差异化**：不只堆 tracker，而是 **「地理/人生坐标叙事」+「结构平衡模型」+「节点最优解候选」** 三位一体。

## 3. 人生是否可以量化？（产品立场）

### 3.1 可量化（APP 主战场）

- **时间结构**：专注、通勤、睡眠、社交频率。
- **资源结构**：财务、技能栈、社交资本（用户自评 + 可选同步）。
- **负荷结构**：工作量、情绪压力频次（自评）。
- **空间轨迹**：出生 A、到访 B/C/D、常驻点、回忆锚点（用户标注）。
- **生活场景 proxy**：生活利用率、穿搭满意度（均为本 APP 内自评，不依赖外部产品）。

### 3.2 宜感受、不宜硬量化（APP 只留叙事位）

爱、尊严、美、意义感、自由感——提供 **「回忆卡片」「节点感悟」** 文本与照片，**不强制打分**。

### 3.3 设计红线

1. **禁止**将人生意义分作为社交排行榜默认能力。  
2. **禁止**「唯一最优解」话术；节点建议一律为 **「参考方案 A/B/C + 理由 + 风险」**。  
3. 用户可 **关闭/隐藏** 任意指标；Goodhart 预警 copy 内置于设置页。  
4. 保留 **「无数据区」**：不记录的空荡、散步、发呆——产品不推送 guilt。  
5. **内容与兴趣对齐**：首页「我关心的方向」驱动展示优先级；指标页每项附带「为何对你有用」说明（MVP 已落地 copy，后续可个性化）。

## 4. 目标用户

|  persona | 描述 | 核心场景 |
|----------|------|----------|
| **探索者** | 20–35 岁，换城/换轨频繁 | 记录 B/C/D，节点顾问（职业、迁徙） |
| **守根者** | 长期生活在 A 附近 | 强调阶段进度、本地关系与满意度，反对「没出过国=失败」叙事 |
| **平衡者** | 30–50 岁，工作家庭并重 | 工作量 vs 资产仪表盘，生活仪式与日常满意度 |
| **回顾者** | 50+ ，退休前后 | 轨迹回顾、回忆地图、阶段总结 |

---

## 5. 核心价值主张

1. **看见轨迹**：在地图/时间轴上看见 A→B→C 与「从未离开的 A」。  
2. **看见结构**：资产、工作量、多巴胺 proxy、意义分——知道是「累」还是「空」。  
3. **节点有的放矢**：在人生阶段关键窗口，给出 **2–3 个可执行参考路径**（含日常生活场景建议）。  
4. **贴身指标进意义分**：生活利用率与穿搭满意度连接「日常状态」与长期结构。

## 6. 功能架构（MVP → 完整）

### 6.1 MVP（与当前 Web 客户端对齐）

- 人生指标仪表盘（资产、工作量、多巴胺、生活利用率、穿搭满意度、意义分）。
- 人生阶段 + 阶段内进度（年龄驱动）。
- 静态 **A 点** 说明 + 手动添加 **B/C 点**（名称 + 可选经纬度/城市）。
- 节点页：**当前阶段** 下 1 个默认「参考建议」卡片（规则引擎，本地）。

### 6.2 v1.0

- 交互式 **人生坐标地图**（标点、回忆摘要、时间范围）。
- **关键节点库**：升学、首份工作、迁徙、重大关系、健康预警、退休规划（每节点多方案）。
- 目标与 OKR -lite：用户设定 1–3 个季度目标，映射到指标权重（自定义意义分权重）。
- 数据导出 / 本地备份。

### 6.3 v2.0（需后端）

- 账号与多设备同步；生活利用率等指标云端备份与恢复。
- 可选健康/记账第三方接入（OAuth，用户授权）。
- 个性化节点建议（在用户明确 opt-in 前提下使用模型，且保留可解释规则层）。

## 7. 指标与公式（产品定义）

与 [量化人生概念](./量化人生概念.md) 一致，面向用户展示时可简化 copy：

| 指标 | 用户可见定义 | 计算要点 |
|------|----------------|----------|
| 资产指数 | 存款、能力、关系资本的自评综合 | 0–100，可手动或分项加权 |
| 工作量 | 通勤、加班、琐事、情绪劳动 | 0–100 |
| 多巴胺指数 | 「净体验」proxy，非医学多巴胺 | `normalize(资产 − 工作量)` → 0–100 |
| 生活利用率 | 计划内常做之事占比或自评 | 0–100%，APP 内手动或规则更新 |
| 穿搭满意度 | 日常自我呈现的主观满意 | 0–100 |
| **人生意义分** | 当前状态下的综合参考分 | 默认：多巴胺 50% + 生活利用 25% + 穿搭 25%（可调） |

**人生阶段（默认）**：出生 0–3 · 学习 3–22 · 实习 22–24 · 工作 24–60 · 退休 60–80 · 死亡 80–100（用于节点触发与叙事，可配置文化/个人例外）。

## 8. 关键节点与「最优解」产品语义

「最优解」在本产品中的定义：

> 在用户当前 **阶段、年龄、指标快照、坐标状态（是否在 A、是否有未完成的迁徙意愿）** 下，由 **透明规则** 生成的 **优先级排序的 2–3 条行动建议**，每条包含预期对指标的影响方向、时间成本、不可逆风险。

示例（工作阶段，工作量高、多巴胺低）：

- **方案 A**：未来 4 周边界实验（拒绝 1 类低价值加班）→ 预期工作量↓、资产→  
- **方案 B**：短途前往新点 D（3 天）恢复空间感 → 预期多巴胺↑、财务小幅↓  
- **方案 C**：仅调整日常仪式（精简日程/习惯）→ 生活利用率↑、穿搭满意度↑  

**不是**：算命、单一正确答案、替代专业心理咨询或医疗。

节点触发类型：

- **年龄阈值**（如 22、24、60）  
- **阶段切换**  
- **指标持续告警**（如 14 天多巴胺 &lt; 35 且工作量 &gt; 70）  
- **用户标记事件**（「考虑换城」）

## 9. 信息架构（顶层）

```
首页（仪表盘 + 阶段摘要）
├── 人生坐标（地图 / 时间轴）
├── 关键节点（待办建议 / 历史决策）
├── 指标详情（单项趋势，MVP 可为静态）
├── 回忆（叙事，非强制量化）
└── 我的（权重、隐私、数据、关于）
```

## 11. 竞品与差异

| 类型 | 代表 | 差异 |
|------|------|------|
| 习惯/健康 tracker | Apple 健康、各类习惯 APP | 本产品有 **结构模型 + 人生阶段 + 坐标叙事** |
| 日记/地图 | 旅行足迹 APP | 本产品强调 **整个人生 A→…→终点**，含「从未离开 A」 |
| 目标管理 | OKR 工具 | 本产品有 **意义分与节点规则**，而非仅任务列表 |

---

## 12. 风险与合规

- **心理健康**：节点文案避免诊断；危机关键词引导至本地求助资源（v1.0 配置表）。  
- **位置隐私**：坐标默认本地存储；精确 GPS 需显式授权。  
- **金融/医疗**：不做投资建议与医疗结论，仅 lifestyle 层自评。  
- **未成年人**：13 以下不注册；青少年模式简化节点与社交。

## 哲学摘要（P1–P3）

- 人生**部分**可量化：时间、健康、财务、成长、情绪等可用于**自我澄清**。
- **不应**量化尽：爱、意义、尊严等以**叙述 + 底线**保留。
- **A → B → C** 轨迹：锚点 A 方差小 ≠ 人生空白；产品 UI 不得暗示「离 A 越远越成功」。

仓库内若仍存在 Vite 版「人生意义分 / 多巴胺指数」演示代码，属于**旧概念原型**，正式产品以 PRD 中的 Expo MVP 为准（无人生总分）。

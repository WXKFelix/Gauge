# 量化人生概念

**量化人生**的目标：用数据帮助每个人**管理和提升**自己的人生。  
本仓库是该项目客户端：可视化个人状态（资产、工作量、阶段、日常满意度等），且只强调**对用户有帮助、且用户愿意关注**的内容。

## 核心公式（概念层）

- **人生意义** ≈ 从当前到未来可感知的正向体验总和  
- **体验 proxy**：多巴胺指数 ∝ **资产 − 工作量**（归一化到 0–100）  
- **综合意义分**：多巴胺 50% + 生活利用率 25% + 穿搭满意度 25%

资产包括：存款、技能、社交资本等可量化积累；工作量包括：通勤、加班、琐事消耗等。

## 人生阶段

| 阶段 | 典型年龄 |
|------|----------|
| 出生 | 0–3 |
| 学习 | 3–22 |
| 实习 | 22–24 |
| 工作 | 24–60 |
| 退休 | 60–80 |
| 死亡 | 80–100 |

仪表盘用当前年龄定位阶段，并显示阶段内进度。

## 生活贴近指标

- **生活利用率**：常做之事 / 计划之事占比，或你自定义的「资源在用程度」自评（0–100%）。  
- **穿搭满意度**：主观打分，对应日常出门状态与自我呈现满意度。

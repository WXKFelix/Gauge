# 量化人生概念

本仓库中的 **Gauge** 仪表盘将「量化人生」与衣橱生活场景结合，用于可视化个人状态而非服务器指标。

## 核心公式（概念层）

- **人生意义** ≈ 从当前到未来可感知的正向体验总和  
- **体验 proxy**：多巴胺指数 ∝ **资产 − 工作量**（归一化到 0–100）  
- **综合意义分**：多巴胺 50% + 衣橱利用率 25% + 穿搭满意度 25%

资产包括：存款、技能、社交资本等可量化积累；工作量包括：通勤、加班、琐事消耗等。

## 人生阶段

| 阶段 | 典型年龄 |
|------|----------|
| 出生 | 0–3 |
| 学习 | 3–22 |
| 实习 | 22–24 |
| 工作 | 24–60 |
| 退休 | 60–80 |
| 死亡 | 80–100 |

仪表盘用当前年龄定位阶段，并显示阶段内进度。

## 与云衣橱的关系

- **衣橱利用率**：已穿/常用单品占比，对应「不让新衣积灰」。  
- **穿搭满意度**：主观打分，对应「出门知道穿什么」的目标。

从 `cloudWardrobe-ui` 的「量化人生概念」分支迁移到 **Gauge** 后，由 React 仪表盘统一展示上述指标。
